# E01-01 新技能分镜重制设计

## 目标

使用 `novel-action-director`、新版 `novel-storyboard` 与 `novel-edit-director`，重制《影帝他总想对我图谋不轨》第一集第一场段 E01-01“棺中惊醒”。本轮用于与现有版本做同条件质量对比，不改剧情，不扩展到整集，不覆盖旧成果。

## 范围与基准

- 仅处理 E01-01，对应剧本 S01 的前五个叙事拍点。
- 保持 5 个镜头、24 fps、341 帧，总时长 14.2083 秒（界面显示 14.2 秒）。沿用项目既有双轨时间权威：投产导入记录精确帧数 `72、63、72、62、72`，官方 storyboard/H3 schema 使用一位小数 `3.0、2.6、3.0、2.6、3.0`；不得用显示秒数反向改写帧数。
- 保留原对白、内心旁白、角色、场景和道具，不新增棺外人物或玄幻特效。
- 旧版图片、分镜 JSON 和视频均保留，所有新成果写入独立目录。
- 角色形象以现有李宝珠人物设定图为身份锚点；由于当前没有独立 `art.json`，场景材质与色彩以剧本、旧镜头和现有资产共同约束。

## 权威输入

- `影帝他总想对我图谋不轨_漫剧改编/剧本/影帝他总想对我图谋不轨-script.json`
- `影帝他总想对我图谋不轨_漫剧改编/人物/影帝他总想对我图谋不轨-cast.json`
- `影帝他总想对我图谋不轨_漫剧改编/人物/images/李宝珠-sheet.png`
- `影帝他总想对我图谋不轨_漫剧改编/分镜/work/episode-01.storyboard.json`
- `影帝他总想对我图谋不轨_漫剧改编/分镜/import/E01-01.cuts.shot-script.json`
- `影帝他总想对我图谋不轨_漫剧改编/分镜/E01-01/f1.png` 至 `f5.png` 作为旧版比较基准，不作为剧情权威。

## 处理流水线

### 1. 动作导演

动作导演的 `ordinaryBeatPreservation` 门要求被深化的动作不能覆盖输入剧本的全部节拍，因此动作阶段使用完整原剧本做来源与普通节拍校验，但只为 E01/S01/B01–B05 建立动作计划；分镜阶段仍使用五拍 scoped script。核心动作链为：

1. 猛然睁眼，在狭窄棺内本能撑顶并确认身体受限。
2. 呼吸急促、沙哑呼救，推顶升级为有目标的拍击。
3. 掌心撞击木盖，明确接触、受力、回弹和闷响后的短暂停顿。
4. 听见回声后压住恐慌，以视线、呼吸和微表情完成“这里不是寝殿”的认知转折。
5. 两手分工：一手触到身下绸缎，另一手探到头顶铜钉，随后全身僵住并得出“在棺材里”的判断。

重点修正旧版中“双手长时间维持同一撑顶姿势”的连续性问题，同时保持写实受力、狭窄空间限制与微表演可见性。原剧本场景没有声明可引用的 prop ID，且棺盖、绸缎和铜钉在本段均不发生状态变化，因此五拍均按 `performance` 深化；手部、接触、回弹和触觉确认写入 phases、边界与 `cameraIntent.mustShow`，不伪造成 `prop-operation`。

### 2. 分镜导演

在不改变五镜头和帧数分配的前提下重新设计构图、机位、镜头运动、景别和关键帧提示词。每个镜头只承担一个主要视觉判断，镜头间必须交接清楚以下状态：

- 头部朝向、肩背受限程度与身体轴线；
- 左右手位置、接触物和动作阶段；
- 棺盖、绸缎、铜钉的相对空间关系；
- 呼吸强度、恐惧程度和认知进展；
- 光源方向、棺内材质、服装和角色身份。

镜头可以在同一景别范围内优化角度与运动，但不得用无依据的大幅运镜或视觉奇观掩盖表演。

### 3. 剪辑边界处理

`novel-edit-director` 的数据契约只处理相邻生成段（segment）之间的边界，不处理同一生成段内部的 cut。E01-01 本身就是一个 14.2 秒生成段，五个镜头之间的四个切点由新版 `novel-storyboard` 的 `startBoundary` / `endBoundary`、动作匹配、视线匹配和声音策略负责。不得为了制造 edit 边界而把 E01-01 错拆成五个短生成段。

本轮仍运行 `novel-edit-director seed/validate/export` 做兼容性核对；预期 `edit.json.boundaries` 与 `transitions.json` 均为空数组。这表示本段内部没有该 skill 所负责的 segment 边界，不代表缺少镜内剪辑设计。新版仍使用官方顺序段 ID `E01-01`，版本隔离由独立父目录承担。真正的 edit-director 深化留到 E01-01 与 E01-02 同时进入范围时执行。

### 4. 图片生成与对比

按重制后的五个镜头分别生成一张关键帧图。每张图必须绑定对应镜头的边界状态与人物身份参考。完成后生成旧版/新版逐镜并排对比材料，便于检查动作表达、人物一致性、空间连续性和整体质感。

## 校验与验收

- action、storyboard 两阶段分别运行各 skill 的官方校验器；edit 阶段运行官方空边界兼容性校验。错误必须修正，警告需逐项判断并记录。
- 5 个镜头的帧数保持 `72、63、72、62、72`，合计 341 帧。
- 剧情覆盖与原 E01-01 相同，无新增对白、角色、道具或棺外画面。
- 每一镜的起止姿态能与前后镜头机械衔接，左右手和道具接触关系无跳变。
- 五张新图中李宝珠身份、服装、发型、棺内光向和主要材质保持一致。
- 最终对比以“动作因果更清晰、微表演更可读、空间与手部连续性更稳定”为质量提升标准，不仅比较画面精细度。

## 非目标与失败处理

- 本轮不生成或替换视频，不改 UI，不导入 StoryboardPro，不处理 E01-02 及后续镜头。
- 不使用 `novel-fantasy-vfx`，因为本段不存在法术、能量或超自然视觉事件。
- 若图片生成服务不可用，仍须完成并校验 action、storyboard，以及 edit 空边界兼容性成果，并明确报告图片阶段阻塞，不以占位图冒充生成结果。
- 若官方 schema 要求的字段与旧导入格式不一致，只做可追溯的机械映射，不改变剧情或镜头时长基准。
