# 《影帝他总想对我图谋不轨》AI 漫剧改编设计

## 目标

将登果儿的古风权谋小说《影帝他总想对我图谋不轨》改编为 40 集、每集约 2 分钟的精致国风 3D 漫剧；本阶段交付完整人物设定、40 集大纲，以及前 3 集结构化剧本与分镜，并生成主要角色定妆图。

## 来源边界

- 原始页面：`https://kol.fanqieopen.com/page/content/book-detail?tab_type=2&top_tab_genre=-1&book_id=7577938070184397848&genre=0`
- 可核对内容：作品简介、41 章目录、前 5 章公开正文。
- 第 6–41 章正文处于锁定状态。后续情节只依据章节标题、前文伏笔及公开简介进行改编推演，不能表述为原著逐章复述。
- 所有关键设定需标注 `原文明确`、`目录推断` 或 `改编新增`，防止事实层级混淆。

## 改编定位

- 类型：女强权谋、悬疑逃亡、双强爱情。
- 核心卖点：万寿公主李宝珠遭人活埋；为寻找奇药“凤凰胎”潜入陵墓的神秘剑客韦训将她救出，两人在互相利用与互相救赎之间卷入皇权争夺。
- 情绪曲线：窒息求生 → 逃亡互信 → 身份背叛 → 复仇登基 → 帝后并肩 → 盛世收束。
- 改编幅度：抽核。保留核心人物、墓中相救、幽州疑局、女帝登基及后期藩镇/西域主线；压缩重复朝争并强化每集钩子。

## 40 集结构

1. 第 1–8 集：墓中苏醒、亡命逃亡、幽州投奔、皇叔疑局。
2. 第 9–16 集：韦训目的与身份暴露，李宝珠情断返京，长安复仇。
3. 第 17–24 集：肃清权臣、女皇临朝、旧盟重建、感情明朗。
4. 第 25–32 集：储君历练、党争、西域使团与内奸案。
5. 第 33–40 集：朔方烽火、深宫主谋、藩镇终局与盛世长歌。

## 首三集设计

- 第 1 集《棺中活人》：活埋冷开场；韦训盗墓开棺；李宝珠第一眼看见的救命恩人却在寻找她体内可能存在的凤凰胎。
- 第 2 集《救我的人想取我心头血》：洞穴互相试探；追兵搜山；二人以利益结盟，向幽州出发。
- 第 3 集《皇叔的城门，是另一座坟》：逃亡路上建立最低限度信任；幽州城门突遭官兵围捕；韦训拔剑护住李宝珠。

## 视觉系统

- 总风格：精致电影级中国动画 3D，写实材质与国风造型结合，避免真人照片感和写实游戏 CG 感。
- 色彩阶段：墓穴青灰；逃亡墨绿与冷褐；皇城赤金；女帝时期黑金。
- 角色一致性：每个主要角色固定脸型、发型、体态、服装层级、标志道具和色彩；剧情阶段变化只改服装状态，不重设计身份特征。
- 画幅：角色设定图 16:9 三区布局；分镜关键帧 16:9。

## 质量门

- 人物 JSON 必须通过 `novel-characters validate`，且引文能在公开正文逐字定位。
- 大纲 JSON 必须通过 `novel-outline validate` 的 13 道质量门。
- 剧本每集目标 120 秒，必须处于 ±15% 容差，并通过 `novel-script validate`。
- 分镜每个生成段不超过 15 秒、节拍全覆盖、台词完整装载、连续性边界相等，并通过 `novel-storyboard validate`。
- 图片生成采用内置 imagegen；先生成主要角色定妆图，再用角色图约束首段关键帧。
