# E01 C19–C22 Hybrid Spatial Rework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a panorama- and camera-bound Codex storyboard path, then use it to regenerate C19–C22 with one physically coherent tomb, complete human bodies, and review-gated outputs.

**Architecture:** A schema-v2 Codex task package binds every spatial-critical request to a versioned Spatial Stage, one approved 2:1 panorama, one saved shot camera, and six rendered control artifacts. A deterministic E01 production script builds the C19–C22 stage and review manifest; the existing Spatial Stage renderer and built-in Codex image generation produce candidates without treating old storyboard images as spatial authority.

**Tech Stack:** TypeScript 5.6, Node.js ESM, React 18, Three.js 0.185, existing Spatial Stage modules, Codex built-in imagegen, existing advanced ComfyUI panorama workflow.

## Global Constraints

- Work on branch `codex/codex-storyboard-task-package`; do not merge to `main`.
- Preserve all unrelated dirty and untracked files.
- The tomb is an enclosed interior; C19–C22 must not contain sky, villages, courtyards, cliffs, or exterior architecture.
- Li Baozhu and Wei Xun always exist as complete head-to-foot humanoid proxies. Visible crop is determined only by the saved camera and physical occluders.
- The phoenix panel stays horizontal in the coffin bottom. The short shovel blade never touches, overlaps, covers, or merges with it.
- Old storyboard candidates are diagnostic evidence only and may not be `spatial_authority`, pose, camera, environment, or composition references.
- The approved panorama must be strict 2:1 and pass 0°, 90°, 180°, and 270° perspective inspection before control export.
- Every C19–C22 task must bind `stageId`, `stageRevision`, `stageDigest`, `snapshotId`, `cameraId`, `cameraDigest`, `panoramaSha256`, and all six control-artifact hashes.
- Save new candidates under versioned names. Do not overwrite current candidate images.
- All new candidates remain `needs_review`. Do not invoke `DaSiWa_MiniMaxH3Video` until the user approves the four images.
- Generate one image per built-in imagegen call; never use CLI/API fallback.
