## Task 1: Exchange protocol and Node validation

Owned paths: `scripts/lib/unity-previs/`, `scripts/check-unity-previs-contract.mjs`, `scripts/unity-previs.mjs`.

Implement `validateExchange(scene)`, `sceneDigest(scene)`, `reflectPosition(v)`, `reflectQuaternion(q)`, `validateExport(directory, expectedScene)`; return validation errors with entity/field context, throw on invalid import.

The JSON DTO uses objects for vectors and quaternions, arrays for collections (Unity JsonUtility-compatible):

```js
const scene = {
  schemaVersion: 1, coordinateSystem: 'RH_Y_UP_METRES', id: 'scene-a', label: 'Scene A',
  source: {stageId:'stage-a',stageRevision:1,stageDigest:'a'.repeat(64),shotId:'shot-a',snapshotId:'snapshot-a',cameraId:'camera-a'},
  camera: {position:{x:0,y:1,z:3},target:{x:0,y:1,z:0},up:{x:0,y:1,z:0},fov:50,near:0.01,far:20,width:960,height:540},
  entities: [], relations: []
};
```

Entity fields: `id,label,role,position,rotation,scale,parts,joints,bones,attachments`. Role is environment/subject/interaction/foreground_occluder. Part: `id,kind,position,rotation,size,color` (RGB float array), kind box/sphere/capsule/cylinder. Joint: `id,parentId,position,rotation,radius,openPoseIndex,hand,handIndex`; positions and rotations are parent-local. Unmapped indexes are -1. Bone: `from,to,radius`. Attachment: `id,jointId,position` with offset local to joint (or root when jointId empty).

Relation fields: `kind,subjectId,targetId,attachmentId,targetPoint,tolerance,interiorMin,interiorMax`. Contact targetPoint is target-local. Inside extents are target-local; checks include subject rendered proxy bounds, not just root.

Export manifest fields: `schemaVersion:1,sceneFile:'scene.json',sceneSha256,preflightFile:'preflight.json',artifacts:[{kind,entityId,filePath,width,height,sha256,encoding}]`. Paths are relative basenames. Kinds: color/depth/normal/visible_mask/isolated_mask/openpose/hand_pose/contact_map. Hash the exact UTF-8 file bytes. Reject stale expected scene using normalized semantic digest (handle Unity float/default serialization without silently ignoring meaningful values).
