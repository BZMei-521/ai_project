# 高风险连续形变路由

以下意图不应交给单段视频模型连续完成：年龄连续变化、城市生长、时代连续变形、跨世界一镜到底、四季连续变形。

处理方式：

1. 分别定义变化前后的稳定人物、场景和道具资产。
2. 在 storyboard 中保证两个端点各自可独立验收。
3. 用 `hard_cut|match_cut|scene_change` 连接；如有共同形状、构图、颜色或声音，再选择相应 method。
4. 在 `stableEndpointAssets` 至少列出两个资产，并在 `intentionalChange` 写清变化字段。
5. 不用遮挡、粒子、模糊或快速运镜掩盖身份和空间漂移。

“一镜到底”是创作意图，不是转场类型；当生成稳定性不足时，稳定资产与可控剪辑优先。
