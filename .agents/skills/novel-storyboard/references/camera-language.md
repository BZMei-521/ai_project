# 镜头语言：从叙事任务到可执行运镜

这不是“高级运镜词库”。先让人物动作、空间关系和信息顺序成立，再决定镜头是否需要动。情绪映射是经验启发，不是质量门；同一种运动在不同调度与剪辑中可以产生相反效果。

## 八个维度不要混写

| 维度 | 回答的问题 | 常用选项 |
| --- | --- | --- |
| 景别 | 观众看多大范围？ | 大远景、全景、中景、特写、大特写 |
| 角度 | 观众从什么权力位置看？ | 平视、低角度、高角度、俯拍、仰拍、过肩、主观 |
| 运动 | 摄影机沿什么路径移动？ | 推、拉、摇、移、跟、升降、环绕、甩镜、穿越 |
| 光学 | 空间关系怎样被镜头压缩或展开？ | 广角、长焦、浅景深、变焦；不能和物理推拉混为一谈 |
| 稳定 | 运动质感是什么？ | 固定、稳定、云台、手持 |
| 构图 | 信息怎样排列与遮挡？ | 前景遮挡、框中框、负空间、对称、引导线、景深转移 |
| 剪辑 | 两个镜头为何能接上？ | 动作匹配、视线匹配、形状匹配、遮挡切、反打、跳切 |
| 调度 | 人物和道具怎样真实移动？ | 走位、朝向、视线、接触、支撑、进出画、屏幕方向 |

## 决策顺序

1. 写清这一切的**信息任务**：交代、揭示、反应、关系、威胁、结果或收尾。
2. 先设计人物与道具的**调度**，确定动作路径、视线、遮挡、工作轴与首尾边界。
3. 选择能看清任务的**景别、角度、构图**。
4. 问：镜头运动是否新增信息、改变心理距离或保持动作连续？若否，选固定镜头。
5. 若是，填写 `cameraPlan` 九字段，再映射到现有 H3 `CAMERA_MOVES`。
6. 最后检查前后镜的动作匹配、视线、屏幕方向、节奏与转场媒介。

## 常用运动的叙事职责

| 运动 | 更可靠的用途 | 常见误用 |
| --- | --- | --- |
| Push In | 缩短心理距离、集中线索、压缩退路 | 每句台词都推，失去重音 |
| Pull Out | 揭示环境代价、疏离、收尾留余韵 | 把应落在反应上的戏拉没 |
| Pan / Truck | 展示关系、跟随横向调度、让新信息入画 | 主体不动却无目的扫景 |
| Tracking | 保持行动临场感和空间连续 | 人物动作不连贯时用跟拍掩盖 |
| Pedestal / Tilt | 揭示高低层级、身份或空间尺度 | 把机位升降与镜头俯仰混写 |
| Arc Shot | 关系反转、包围感、能量或局势重排 | 无空间锚点地 360° 乱绕 |
| Zoom | 光学压缩/拉伸注意力，制造不自然感 | 当成物理推拉的同义词 |
| Handheld / Shake | 危机、崩溃、身体临场；接触处可短促脉冲 | 全段持续抖，观众失去接触点 |
| Whip / 穿越 | 强方向性转场、追逐、突发切入 | 为炫技破坏屏幕方向 |

## 情绪镜头只是启发式

- 缓推常用于压迫、认知逼近或情绪聚焦；也可能表达亲密。
- 后撤常用于疏离、失去或揭示人物被环境吞没；也可能表达释然。
- 环绕可能表达眩晕、关系升温或局势翻转，取决于人物调度和声画节奏。
- 手持可以表达崩溃，也可以表达纪录式亲近。没有明确情绪任务就不用。
- 高角度、俯拍常强化孤立或秩序；低角度常强化权威或威胁，但构图、表演和上下文优先。

## 动作与打击镜头

动作戏先保证“准备 → 接触 → 反馈 → 恢复/倒地”的受力链。镜头只负责让证据可读：

- 接触前保留蓄力方向和接触窗口；不要提前把主体切丢。
- 接触时可以短促推近、轻微抖动或动静对比，但必须立刻回稳。
- 接触后给目标迟滞、支撑脚变化、重心偏移或全身失衡；特效不能代替这些信息。
- 低机位突进、弧线跟进、贴地掠行等只在能强化路径和力量时使用。
- 重叠镜头至多两段，每段提供不同证据；慢动作不覆盖完整发力。

## 转场与连续性

转场优先寻找真实连接：前景遮挡、门框、人物进出画、动作匹配、视线、光源、声音桥或同形构图。转场必须说明前镜动作、连接媒介、镜头移动、后镜场景与信息变化。场景断层时先修空间和动作连续性，不用闪白、粒子或甩镜掩盖。

## 克制规则

- 一段通常只用一两个显著运动；固定镜头是有意识的选择。
- 同一运动重复前先问它是否仍提供新信息。
- 人物动作接不上时先修调度和边界，不升级运镜。
- 没有叙事动机就不填 `cameraPlan`，旧分镜保持简洁有效。
