# 法术效果深化顺序

1. 逐节拍筛选：只选择能力显形、边界变化、接触结果或持续状态对叙事有用的节拍。
2. 锁来源：复制 scene、beat 与原文，不改写结果。
3. 定功能：回答“这次效果在剧本里做了什么”，未知就不补。
4. 定边界：明确开始状态、结束状态与是否跨节拍持续。
5. 画拓扑：先原点和尺度，再形状、节点、回路；不要先堆颜色和粒子。
6. 排生命周期：逐相写可观察状态与相邻转换。
7. 写环境响应：只写该尺度下真实可见的空气、尘、水、光、植被或物体反馈。
8. 接动作：已有 action.json 时只填引用，不复写手势与重心。
9. 列 mustShow：只保留分镜必须呈现的拓扑、接触和结果事实。
10. 标风险并验证：细符文、多层镜像、密集粒子、多人遮挡、大环境必须显式标记。

普通对白不自动生成效果。连续法术优先复用同一效果 ID 与状态，不要每个镜头重新起法术。
