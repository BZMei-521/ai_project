# 生命周期与跨节拍连续性

## 单次生命周期

dormant → charging → forming → active → impact → dissipating → residue。可以跳过与剧本无关的相，但不能倒序；每次跳转仍须声明前后状态和转换。

## 跨节拍持续

- 仍在作用：末态 persistence: continuing，下一节拍起始状态必须接上上一末态。
- 暂停但保留：明确静止的拓扑、亮度与边界，不能凭空回到充能。
- 已结束：persistence: ended，下一次再施放视为新生命周期。
- 残留：焦痕、霜、余电、漂浮符纸、水迹等必须在后续场景被保留或明确清除。

## 连续性清单

- 同一效果 ID、颜色、形状、节点位置是否稳定。
- 人物、道具与环境锚点是否仍存在。
- 能量是否有来源、去向和守恒感。
- 受击波纹、裂纹或残留是否与上一节拍一致。
- 切镜或转场不能替代状态转换；镜头变化由 storyboard/edit skill 决定。
