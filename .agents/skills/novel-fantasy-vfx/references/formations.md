# 阵法与结界拓扑语法

阵法先回答五件事：阵心在哪里、边界是什么、节点有几个、节点怎样连通、力量向内还是向外流。

## 结构字段

- shape：circle、bagua-circle、five-point、grid、lotus、sword-ring、star-map、mirror-plane 等。
- origin：人物脚下、道具、门槛、山门、空中锚点等具体位置。
- nodes：可追踪的阵眼或锚点；名称保持短而稳定。
- circuits：节点之间实际连线，禁止只有节点没有回路。
- scale：hand/body/room/scene/world。
- active boundary：屏障、杀域、困域或传送面，只能由剧本功能确定。

## 16 类学习素材的决策线索

- 八卦阵：阴阳旋转、八方节点、攻防兼容的圆形地面拓扑。
- 五行阵：金木水火土五节点与相生/相克回路；结果仍看剧本。
- 太极两仪阵：双区旋流、明暗对冲、平衡轴。
- 天罡北斗阵：七星节点、星轨连线、由天到地的压力方向。
- 周天星斗大阵：多层星盘、天体级环带；通常触发大环境风险。
- 万剑归宗阵：剑阵向中心汇聚或从中心放射，注意密集遮挡。
- 青莲剑阵：莲瓣分层、柔性曲线与锋利边缘并存。
- 九天玄雷阵：垂直雷柱、地面引雷节点、接地回路。
- 炎阳焚天阵：热源中心、外扩火环、空气热扭曲。
- 寒冰封天阵：冰晶节点、冻结传播前沿、冷雾残留。
- 沧海潮生阵：潮汐环、旋涡回路、水位与反射变化。
- 九宫锁灵阵：九格区域、锁链或边界连接、空间限制。
- 镇魔封神阵：柱状锚点、向内镇压、厚重边界。
- 护山大阵：地形锚点、山门级屏障、世界/场景尺度风险。
- 镜花水月阵：镜面层、倒影错位、虚实切换；声明多层镜像风险。
- 血煞炼魂阵：红色回路、向心压迫与残留污染；不得自行推断伤亡。

阵名只选结构语言，不授权效果结果。阵眼被破、法阵反噬、封锁成功等必须来自剧本。
