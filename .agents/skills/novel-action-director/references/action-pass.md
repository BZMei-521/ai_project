# 动作深化流程

## 1. 选择节拍

仅在下列情况建立完整动作计划：剧情转折依赖动作结果；角色关系通过接触或距离改变；身份/道具状态发生变化；战斗、追逐、跌落等存在物理风险；表演需要微表情才可读；镜头必须看清动作爆点。

普通动作不升级。不要为了“画面丰富”给每个 beat 填一套 phases。

## 2. 固定事实

先从 seed 复制集、场、beat、角色、道具和原文。写 `intent` 时只能解释原动作为什么发生，不能增加新结果。

## 3. 写状态边界

先写 `startState` 和 `endState`，再写过程：

- 人物：位置、朝向、支撑、重心、视线、左右手、正在接触的对象。
- 道具：持有者、手、位置、开合/完整/装填等状态。
- 双人：距离、接触点、谁支撑谁、双方稳定姿态。

若相邻动作首尾不一致，必须以 `continuity.timeJump: true` 明确时间跳跃；不要靠提示词暗示跳变。

## 4. 写因果链

按适用阶段填写。每一段只承担一个物理或表演变化。主动作前写预备，接触后写反应，最后写稳定姿态。衣发惯性、道具余摆属于次级运动，不能代替主体动作。

## 5. 标记可生成风险

下列情况必须列入 `generationRisk`：精细手指、多角色遮挡、复杂肢体纠缠、武器碰撞、快速旋转、腾空落地、道具状态细变。风险用于分镜拆解和模型选择，不是禁止项。

## 6. 约束镜头意图

`cameraIntent.mustShow` 写信息：接触点、手部状态、受力结果、落点、视线关系。不要写推镜、拉镜、环绕、焦段、景别或镜头速度。

## 7. 验证顺序

先修来源与边界，再修动作因果，再修连续性/物理档位，最后处理生成风险。若 18 门中任何一项失败，不得 export。
