# 表演与微表情

## 写过程，不写标签

使用：`触发事件 → 控制程度 → 可见通道 → 泄露动作 → 释放/恢复`。

“愤怒”“悲伤”“开心”本身不可执行。改写为可观察变化，例如：听见名字后先压住抬头冲动，视线仍落在杯沿；下颌绷紧半拍，呼吸延迟，右拇指无意识摩擦杯口；随后慢慢呼气。

## 按可见尺度选择通道

- 近距离：眼睑、眉形、注视点、嘴角、下颌、吞咽、呼吸。
- 中距离：头颈、肩背、手部、重心、与他人的距离。
- 远距离：步态、停顿、转身、靠近/远离、整体轮廓。

动作计划只标记“必须看清的通道”，具体景别交给分镜。

## 同一种情绪的层级

- 快乐可从嘴角轻扬、眼神先亮，到呼吸放松、笑意扩散，再到全身打开。
- 愤怒可从视线变冷、唇线收紧，到眉心锁住、重心前压，再到爆发动作。
- 悲伤可从目光下垂、嘴角失力，到眼眶含水、呼吸不稳，再到失去支撑。

层级必须服务剧情，不按性别套模板。反笑、强颜欢笑、沉默收住等反向表演要写清“控制”和“泄露”的先后。

## 检查

- 触发是否具体？
- 注视对象是否明确？
- 至少一个身体通道是否发生变化？
- 泄露动作是否与控制策略形成张力？
- recovery 是否能接下一句台词或动作？
