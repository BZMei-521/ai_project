# 表演通道组合

情绪词只是方向，动作计划必须写可观察变化。优先选择 2–4 个通道形成过程，不要让所有部位同时夸张。

## 八个通道

| 通道 | 可观察变化 |
|---|---|
| 眼与眼睑 | 眨眼延迟、眼睑收紧或放松、泪膜、瞳孔注视稳定性 |
| 眉 | 眉心锁紧、单眉抬起、眉尾下沉或松开 |
| 口与下颌 | 唇线收紧、嘴角偏移、下颌咬紧、吞咽、短暂张口 |
| 呼吸 | 屏息、吸气变浅、呼气延迟、一次长呼气、呼吸失序 |
| 肩与躯干 | 肩颈抬起或放松、胸腔收拢、躯干前倾或后撤 |
| 手与自我接触 | 指节收紧、揉捏衣角、护住身体、触碰脸颊、松手 |
| 注视目标 | 直视、回避、侧看、追随、视线固定在道具或出口 |
| 关系距离 | 靠近、停在半臂外、退后、侧身让位、挡住去路 |

## 常用组合

- 克制的喜悦：眼神先亮，嘴角随后轻抬，肩颈放松，呼气恢复；不要直接跳到大笑。
- 隐忍的愤怒：注视固定，眉心收紧，下颌咬住，呼吸变浅，握力增加；爆发必须由新触发推动。
- 强忍悲伤：视线下垂或移开，眨眼延迟，喉间吞咽，呼气受阻，手寻找稳定接触；落泪不是必选结果。
- 恐惧：眼睑扩大后快速搜索出口，呼吸短促，肩颈抬起，躯干后撤，关系距离增加。
- 惊讶：眼睑和眉先变化，吸气短暂停住，嘴唇微张，重心短暂冻结；恢复后再决定靠近或后退。

## 填写顺序

1. 写触发和注视目标。
2. 写角色试图控制什么。
3. 选择最先变化的通道，再写第二个泄露通道。
4. 写手部、呼吸或距离如何把情绪带到全身。
5. 以可承接的稳定姿态结束。

不按性别分配姿势，不把“温柔”“霸气”“悲伤”当作动作，也不依赖脸部大幅变形表达强度。
