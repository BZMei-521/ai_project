# 战斗、攻防与受力

## 完整因果

战斗必须包含：

```text
setup → anticipation → action → contact → reaction → recovery
```

- `setup`：双方位置、支撑脚、武器/手部状态。
- `anticipation`：蓄力、重心转移、攻击意图是否被读到。
- `action`：攻击主体、轨迹、方向、速度与支撑。
- `contact`：命中/格挡/擦身点、力方向、强度和结果。
- `reaction`：目标身体、步伐、武器和情绪的同步反馈。
- `recovery`：攻击者与目标都回到可承接姿态。

## 三类结果

- 命中：写清接触点、力方向、目标位移/姿态结果。
- 格挡：写清双方武器或肢体碰撞位置，以及冲击如何传递到手臂、躯干和脚下。
- 闪避：写清原攻击轨迹、躲避路径和落点，不能只写双方分别摆姿势。

受击是否有力感，主要看目标反应，不看特效数量。后仰、旋转、击飞必须能从接触力和支撑关系推导出来。

## 动态与镜头信息

动作可使用低机位、跟随、环绕、快速推近等视觉策略，但 action 层只写需要看清的爆点、轨迹、接触与结果。具体机位和运动由 storyboard 选择。

残影、速度线、粒子、火花、震屏、动态模糊是可选表现。先保证人体、武器轨迹和受力成立，再决定是否需要效果。

## 生成风险

武器交叉、多人围攻、空中旋转、地面翻滚、手指结印、遮挡下的接触都应标记风险。必要时让 storyboard 拆成预备—接触—结果多个镜头，不在单帧塞入完整连续动作。
