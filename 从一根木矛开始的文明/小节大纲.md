# 《从一根木矛开始的文明》小节大纲
###1.
- 情绪：骤然绝境到侥幸获救。
- 子事件：狼牙逼近；岚用木矛救援；发现兽耳猎手；语言不通；流浪人去留争议。
- 关系变化：岚只因职责救人，对林越保持戒备。
- 道具：救命木矛首次出现。
- 节尾钩子：部落决定天亮后把林越留在荒野。
###2.
- 情绪：绝望中出现希望，旋即压上灭族倒计时。
- 子事件：系统迟到上线；语言精通生效；鉴定部落环境；七日寒潮；死亡率百分之七十三。
- 关系变化：林越第一次听懂岚，但隐藏系统来源。
- 因果：必须在被驱逐前让部落相信预警。
- 节尾钩子：林越听见天亮驱逐决定。
###3.
- 情绪：受疑与孤注一掷。
- 子事件：候鸟、狼脚冻伤、岩缝结霜组成证据；枯羽反驳；岩山裁决；一天证明期限。
- 关系变化：岚愿意带他参加一次狩猎，但不为他担保。
- 节尾钩子：失败就独自面对即将降临的寒潮。
###4.
- 情绪：第一次能力兑现。
- 子事件：制作投矛器；岚纠正本地兽性判断；绳套与驱兽阵配合；猎获两头巨角鹿。
- 技术：知识必须由猎队执行，林越也会判断失误。
- 关系变化：岚承认他有用，岩山授予有限调度权。
- 节尾钩子：七日倒计时只剩六日。
###5.
- 情绪：建设兴奋转为失败焦灼，再迎来小成。
- 子事件：挖排水沟；制陶首窑炸裂；错误烟道险毁鹿肉；调整泥料与烟道；第二窑成功。
- 技术：材料、阴干时间、火候和分工均有成本。
- 道具：岚的绿色佩饰第一次出现。
- 节尾钩子：北风提前转向。
###6.
- 情绪：救命压力与信任升温。
- 子事件：岚的弟弟误食毒根；系统鉴定；洗胃补水与草药处理；孩子脱险；岚交出兽牙。
- 关系变化：从能力认可进入私人信任，尚不表白。
- 节尾钩子：林越在狼尸脚掌发现冻裂伤。
###7.
- 情绪：认知反转与计划崩塌。
- 子事件：狼尸消瘦、冻伤与迁徙方向；揭示狼群在逃离极寒；寒潮提前一夜；枯羽带人去旧洞。
- 反转：狼群既是威胁，也是更大灾难的证据。
- 节尾钩子：暴雪中传来旧洞坍塌声。
###8.
- 情绪：最坏时刻仍选择救人。
- 子事件：旧洞冻裂积水后坍塌；绳索支撑救援；岚与林越冒雪入洞；枯羽获救并认错；文明协作评分上涨。
- 关系变化：两人可以把后背交给对方。
- 节尾钩子：狼嚎从暴雪外逼近未完工侧翼。
###9.
- 情绪：全篇最高峰，集体守护。
- 子事件：壕沟、拒马、树脂火墙和集中投矛依次生效；狼王突破侧翼；林越与岚守门；枯羽回援；木矛杀狼王。
- 回收：开篇木矛完成第二次意义转换。
- 节尾钩子：系统提示文明条件全部达标。
###10.
- 情绪：劫后安静、归属和文明初火。
- 子事件：确认无人死亡；岩山授予传火者身份；青铜时代解锁；认出孔雀石；岚将兽牙系回木矛；第一滴青铜入模。
- 回收：兽牙、孔雀石、木矛全部闭环。
- 收尾：不展望宏大未来，停在具体动作和熔液上。
###11.
- 情绪：建设成果的兴奋被外来伤口打断。
- 子事件：第一枚青铜矛尖成形却布满气孔；石牙改进炭窑和风囊；青禾带狐族伤员逃入谷地；空盐袋和被割掉的族纹揭示赤鬃征贡；赤鬃使者抵达。
- 关系变化：岚接受青禾参与矿场警戒，林越开始把技术用于部落之外的人。
- 技术与成本：铜料稀少，第一枚矛尖消耗四次冶炼所得的大半铜液。
- 道具：第一枚青铜矛尖和赤鬃盐砖出现。
- 节尾承接：使者把盐砖扔上公共石板，要求石牙用矿和人口换盐。
###12.
- 情绪：受辱、愤怒与资源倒计时。
- 子事件：赤鬃索要铜矿、冶炼方法和二十名族人；岩山当众拒绝；使者宣布封锁盐路；系统计算储盐天数；林越与岚勘察旧盐源失败。
- 关系变化：岩山愿意让青禾参加粮盐议事，青禾第一次把狐族命运押在石牙的选择上。
- 技术与成本：系统无法制造盐，硬抢盐路会消耗伤员需要的盐水和全部猎队。
- 节尾承接：林越决定先用石牙能制造的东西撬开其他部落的门。
###13.
- 情绪：互不信任中的微弱希望。
- 子事件：青禾带林越拜访鹿溪和长耳两个部落；陶罐、铜凿和熏肉换来盐与情报；铜环统一计量；各族拒绝立即出兵；枯羽把第一份共同约定刻上骨板。
- 关系与制度变化：松散互助网络形成，各族第一次用同一尺度分粮，不再只靠首领口头担保。
- 技术与成本：铜凿只能提供少量样品，石牙必须以技术培训代替无限送工具。
- 伏笔：青禾询问西侧备用山路和各族烽火习惯。
- 节尾承接：南坡升起黑烟，铜矿遭到袭击。
###14.
- 情绪：愤怒追击转为认知裂口。
- 子事件：赤鬃小队毁坏炉体和矿架；岚带队截住撤退者；俘虏身上有不同族纹；青禾认出他们是被扣住家人的附属战士；林越拒绝把俘虏变成石牙奴隶。
- 关系变化：被俘战士第一次愿意提供赤鬃营地情报，青禾确认林越的规则不是空话。
- 技术与成本：损坏炉体需要重建，矿石与木炭运输被迫暂停。
- 伏笔：附属战士说明人质被集中看管，赤鬃军队并非铁板一块。
- 节尾承接：烈鬃正在集结远超石牙人数的战士。
###15.
- 情绪：建设忙碌、联盟摩擦与规则落地。
- 子事件：统一矛杆和盾阵口令；演练烽火；铜环登记粮食；熊族与狐族因分粮争执；岩山同意各族共同议事；青禾安排空粮车试走备用山路。
- 关系与制度变化：岩山让出部分分配权，枯羽从记录石牙祖规转为记录各族共同决定。
- 技术与成本：青铜只用于刃口和关键工具，大多数战士仍使用石矛与木盾。
- 伏笔：备用山路、空粮车、统一烽火暗号全部落地；青禾暗中接触赤鬃附属战士。
- 节尾承接：烽火演练结束当夜，真正的敌情提前出现。
###16.
- 情绪：首战受挫、误解与绝境退守。
- 子事件：烈鬃提前进攻并用湿皮压制火沟；外围盟友按密令带空车撤向西路；石牙族人误认为遭背叛；岚用青铜矛尖掩护撤退；矛尖折断；石牙放弃铜矿。
- 关系变化：林越选择相信青禾的计划，岚压住族人追击盟友的冲动，两人共同承担退守决定。
- 技术与成本：赤鬃针对石牙旧战法调整，标准装备只能延缓败势，不能弥补人数差。
- 伏笔：撤走者留下主粮和伤员，只带空车与引火材料；西侧烽火迟迟未亮。
- 节尾承接：赤鬃大军抵达谷口，烈鬃要求日出前献出林越。
###17.
- 情绪：围城绝望推至全篇爽感峰值。
- 子事件：赤鬃以人数和湿皮盾压迫谷口；石牙用木盾阵、集中投矛与旧壕沟拖延；西侧烽火亮起；盟友切断盐粮运输；青禾救出人质；附属战士倒戈；烈鬃阵线崩溃并被俘。
- 关系与制度变化：各族第一次以联盟身份共同作战，胜利不归属于单一首领或单件武器。
- 技术与成本：石牙耗尽大半投矛和储粮，铜器只在破盾与修筑中发挥局部作用。
- 回收：备用山路、空粮车、烽火暗号、人质线和折断矛尖全部得到解释。
- 节尾承接：胜利后的第一场争执不是庆功，而是如何处置俘虏、盐路和铜矿。
###18.
- 情绪：余震、克制与温暖归属。
- 子事件：各族讨论俘虏和盐路；拒绝推举林越为王；枯羽主持共同盟誓；岩山让出部分决定权；盐砖被砸碎分食；铜环成为共同族纹；岚与林越共用火塘。
- 关系与制度变化：谷地盟约确立不掠人口、共同守路、按贡献分配矿盐和各族共同议事；林越与岚正式确认伴侣关系。
- 技术与成本：系统提示下一阶段条件尚未满足，林越关闭面板，继续处理眼前的联盟议事。
- 回收：盐砖、铜环、兽牙、木矛与火塘完成最终闭环。
- 收尾：不同族群把各自族纹刻入同一块铜板，停在最后一道新鲜刻痕上。
